# skills

Личные переносимые Agent Skills. Процедуры находятся здесь; факты, инструкции доступа и состояние конкретных проектов остаются у их владельцев.

| Skill | Назначение |
|---|---|
| [docs](docs/SKILL.md) | Документация как проверенная память, поиск контекста, чтение по разделам и передача работы |

## Использование

Можно подключить всю папку `docs/` средствами своего агента. `SKILL.md` — точка входа; дополнительные материалы читаются по потребности. Сам skill не зависит от Codex или внешнего memory-сервиса. Необязательный офлайн-помощник требует Git и Python 3.9+.

Подключение через [open skills CLI](https://github.com/vercel-labs/skills):

```sh
npx skills add sekachev/skills --skill docs
```

Это устанавливает skill в выбранный проект; глобальную установку выбирает пользователь отдельно. Автоматический выбор зависит от поддержки skills агентом. Для постоянного соблюдения метода краткое правило обновления документации нужно в существующих инструкциях проекта; skill описывает, как его исполнять.
