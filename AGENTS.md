# Работа с переносимыми skills

Сохраняй KISS и DRY: короткая процедура, дополнительные материалы по потребности, scripts только для повторяемой механики. Правки должны менять полезное поведение агента, а не расширять каталог ради полноты.

Не добавляй факты конкретного клиента, личные локальные пути, credentials или обязательные зависимости от пользовательских skills. Не устанавливай skill глобально и не меняй сторонние проекты при разработке этого набора.

Источники идей принадлежат references; не копируй чужие руководства в основной skill. Метаданные и имя папки должны соответствовать Agent Skills specification. Общие знания не требуют отдельного документа.

Перед отправкой изменений запускай `python3 -m unittest discover -s tests` и `git diff --check`. Для изменения процедуры проверь хотя бы один реалистичный сценарий; для скриптов — существенные границы поведения. Статическая проверка SKILL.md не доказывает правильность решений агента.
