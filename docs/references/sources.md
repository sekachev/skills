# Источники и принятые решения

Исследовано 07.10.2026. Это синтез общих идей, а не копия чужих skills. Числовой ориентир 500 строк — наша эвристика, не стандарт и не доказанная граница качества.

- [Anthropic: Effective context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents): загрузка по потребности через пути и ссылки; компактные заметки; изоляция объёмного исследования. Взяли минимальный достаточный контекст и сводки с сохранением существенных условий. Не предполагаем доступ к управлению контекстным окном конкретного runtime.
- [LangChain: Memory overview](https://docs.langchain.com/oss/python/concepts/memory): различение состояния сессии, устойчивых фактов, опыта и процедур. Используем различие назначений информации; не требуем LangGraph, базу данных или отдельный файл для каждого типа.
- [Agent Skills specification](https://agentskills.io/specification): компактный SKILL.md, ресурсы по потребности, переносимые относительные ссылки. Это упаковка процедуры; факты конкретного проекта не входят в общий skill.
- [Agent Skills for Context Engineering](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering): изучены filesystem-context, context-compression и memory-systems. Полезны файловая память, компактная передача состояния, область применимости и пересмотр устаревших знаний. Не переносим набор взаимозависимых skills, сравнения memory-frameworks, графовые хранилища или автоматическое изменение правил.
- [llms.txt proposal](https://llmstxt.org/): короткий вход с пояснениями и ссылками на детали. Применяем принцип навигации; не требуем llms.txt в каждом локальном проекте и не считаем его гарантией актуальности.
- [Docs as Code](https://www.writethedocs.org/guide/docs-as-code/): документация участвует в обычном процессе изменения, review и проверок. Сохраняем workflow владельца, не навязываем отдельный CI.
- [Diátaxis](https://diataxis.fr/how-to-use-diataxis/): структура развивается из потребностей читателя и небольших полезных исправлений. Не создаём заранее пустую иерархию документов.
- [Lost in the Middle](https://arxiv.org/abs/2307.03172): исследование показывает зависимость качества поиска от положения информации в длинном контексте для исследованных моделей и задач. Мотивирует точное чтение; не переносим измеренные эффекты на все современные модели и не обещаем численную экономию.

Практическое ядро сформировано из метода единственного владельца факта, производного индекса и обновления документов вместе с работой. В общий skill перенесена процедура без идентификаторов, доступа и предметных данных исходного проекта.
